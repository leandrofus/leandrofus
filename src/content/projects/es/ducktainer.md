Una herramienta integral de administración de Docker diseñada para ser ultra liviana, sin requerir pesados servidores adicionales. Se compila en un único binario ejecutable e incluye interfaz gráfica web interactiva, soporte para túneles Cloudflare, emulador de terminal interactivo para contenedores y autenticación contra el sistema operativo anfitrión.
